# موقع د. مصطفى عباس

موقع تعريفي عربي باتجاه RTL للدكتور مصطفى عباس، استشاري أول مخ وأعصاب وطب نفسي أطفال.

## التقنيات
- Next.js 15
- React 19
- TypeScript
- تصدير HTML ثابت للنشر على Cloudflare Pages

## التشغيل محليًا
يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## البناء
```bash
npm run build
```

ملفات الموقع الجاهزة للنشر ستكون داخل مجلد `out`.

## النشر على Cloudflare Pages
- Framework preset: Next.js (Static HTML Export)
- Production branch: main
- Build command: `npx next build`
- Build output directory: `out`

اربط المشروع بمستودع GitHub من لوحة Cloudflare Pages. بعد الربط، كل تحديث على فرع main سيؤدي إلى بناء ونشر تلقائي.

## ملاحظات قبل النشر النهائي
- أضف صورة الدكتور الأصلية إلى `public/images/doctor.jpg` بعد استلامها، ثم يتم استبدال مساحة الصورة المؤقتة بها.
- أضف الدومين المخصص بعد اختياره.
- راجع أرقام الهاتف ومواعيد العيادات قبل الإعلان عن الموقع.
- ساعات عيادة طنطا غير محددة في البيانات المتاحة، لذلك لم يتم اختراع ساعات عمل لها.
- الحجز بالحضور في العيادات الثلاث.

## الخصوصية
لا توجد مفاتيح API أو بيانات سرية مطلوبة لتشغيل النسخة الحالية. لا ترفع كلمات مرور أو مفاتيح خاصة إلى المستودع.
